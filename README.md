
# ServiceDesk Pro 🎫

ServiceDesk Pro is a full-stack IT Service Management system designed to help organizations manage and resolve employee IT support requests efficiently.

## 🚀 Features

* 🔐 User Authentication & Role-Based Access
* 🎫 Create and Manage Support Tickets
* 👨‍💻 Employee, Support Agent & Admin Roles
* 🔄 Ticket Status Workflow
* 💬 Ticket Comments & Resolution
* 🔎 Search, Filter & Pagination
* 🛡️ Secure REST APIs

## 🛠️ Tech Stack

* **Backend:** Java, Spring Boot, Spring Security, JPA/Hibernate
* **Database:** MySQL
* **Frontend:** React.js
* **Authentication:** JWT
* **Build Tool:** Maven
* **Deployment:** Docker

## 🏗️ Architecture

React.js → Spring Boot REST APIs → Service Layer → JPA/Hibernate → MySQL

## 🎯 Purpose

The project simulates a real-world enterprise IT support system where employees can raise issues, support agents can manage and resolve them, and administrators can manage the overall system.
